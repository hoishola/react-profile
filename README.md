# Personal Portfolio (React)

My personal developer portfolio, built with React. Replaces my earlier plain HTML/CSS/JS site as my main portfolio going forward.

## Live Site
hoishola.com

## Features
- Dark themed, terminal inspired design with monospace accents
- About section covering my background and current focus
- Tech stack overview
- Project cards for StyleMate and my original Personal Website V1, each with details and links
- Downloadable resume
- Contact section with email and LinkedIn

## Built with
- React
- Vite
- Deployed on Netlify

## About this project
This portfolio replaced hoishola.com's original plain HTML/CSS/JS build. The old version is kept as a project entry on this site rather than staying live, as a record of where I started.
